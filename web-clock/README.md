# Digital Clock

A clean, modern digital clock built with vanilla HTML, CSS, and JavaScript.

## Features

- **Live time** — updates every second in HH:MM:SS format
- **12-hour / 24-hour toggle** — click the button to switch modes
- **Current date** — displayed below the time
- **Dark theme** — easy on the eyes
- **Responsive** — scales nicely on any screen size
- **Zero dependencies** — no libraries or CDNs required

## Usage

Open `index.html` in any modern web browser. That's it.

```
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```
